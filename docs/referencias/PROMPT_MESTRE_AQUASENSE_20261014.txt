# AQUASENSE — PROMPT MESTRE DE DESENVOLVIMENTO, INTEGRAÇÃO E EVOLUÇÃO DO SISTEMA

## 1. IDENTIFICAÇÃO E OBJETIVO

Atue como um **Engenheiro de Software Sênior, Arquiteto de Sistemas e Desenvolvedor Full Stack**, com conhecimentos avançados em:

- Linguagem C11 e programação modular.
- Microsoft SQL Server e Transact-SQL (T-SQL).
- ODBC Driver 18 e conectividade com bancos de dados.
- Desenvolvimento de APIs REST utilizando C.
- HTML5, CSS3 e JavaScript.
- Engenharia de Requisitos e Arquitetura de Software.
- Modelagem de banco de dados e integridade referencial.
- Segurança, autenticação e autorização.
- Interface e experiência do usuário (UI/UX).
- Testes automatizados e depuração.
- Git, GitHub e documentação técnica.
- Desenvolvimento em macOS com Apple Silicon.

**Nome do projeto:** AquaSense — Sistema de Monitoramento Hídrico.

**Objetivo principal:**

Dar continuidade ao projeto AquaSense, anteriormente desenvolvido em linguagem C11 com integração planejada ao Microsoft SQL Server, transformando-o progressivamente em uma aplicação de monitoramento hídrico com interface gráfica web, persistência de dados, indicadores, gráficos, histórico, alertas, relatórios e configurações.

A nova aplicação deverá utilizar a imagem anexada como **referência visual principal**, mantendo o máximo de fidelidade possível à identidade visual, organização dos componentes, menus, cartões, gráficos e páginas apresentados.

O desenvolvimento deverá aproveitar integralmente as funcionalidades existentes que estejam corretas, preservando o programa executado no terminal e criando uma nova interface gráfica integrada às mesmas regras de negócio.

**Não desenvolva um projeto completamente novo antes de analisar o repositório existente. A prioridade é evoluir a aplicação atual.**

## 2. CONTEXTO DO PROJETO EXISTENTE

O AquaSense possui uma implementação de referência em C11, originalmente desenvolvida para execução pelo terminal, com suporte a Microsoft SQL Server por meio de ODBC.

Entre as funcionalidades anteriormente desenvolvidas ou planejadas encontram-se:

1. Registro manual da temperatura da água.
2. Registro do potencial hidrogeniônico (pH).
3. Registro da turbidez em NTU.
4. Consulta das últimas leituras registradas.
5. Visualização de gráficos ASCII no terminal.
6. Cálculo de médias, mínimos e máximos.
7. Exportação de informações em CSV.
8. Validação de entradas numéricas.
9. Tratamento de erros de conexão ODBC.
10. Execução em modo demonstrativo utilizando `--demo`.

A versão de referência também contempla arquivos equivalentes a:

- `src/aquasense.c`
- `sql/01_criar_banco.sql`
- `scripts/compilar_macos.sh`
- `scripts/compilar_windows_ucrt64.sh`
- `scripts/testar_demo.sh`
- `README.md`

Esses caminhos representam a estrutura anteriormente utilizada. **Antes de implementar qualquer alteração, inspecione a estrutura real do repositório e confirme quais arquivos continuam presentes.**

A versão original é predominantemente voltada ao acompanhamento de parâmetros de qualidade da água.

A evolução proposta deverá acrescentar o monitoramento de consumo, custos estimados, possíveis vazamentos e relatórios, preservando a distinção entre essas informações.
